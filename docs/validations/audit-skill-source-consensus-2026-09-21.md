# Hero skill-text source consensus audit — 2026-09-21

This is a one-time comparison of downloaded `source.json` skill text
against [Yaphalla Heroes](https://www.yaphalla.com/heroes/) and
[Prydwen characters](https://www.prydwen.gg/afk-journey/characters).

## Scope and decision rule

- **126 heroes** and **750 skill records** were covered by all three
  inputs. The retained raw captures are in ignored `tmp/` artifacts.
- The audit compared only `description.raw` and
  `description.upgrades[].text`; names, summary text, unlock metadata,
  cooldowns, range, and energy were excluded.
- A correction required both live sources to agree against the local
  text on every changed mechanic, numeric value, target, condition,
  duration, area, and tier. Styling and Prydwen's omitted scaling
  annotations were not treated as factual differences.
- **35 correction units across 22 `source.json` files** met that rule.
  One worker suggestion (Hodgkin Ultimate) was rejected during
  collection because its difference was only an equivalent omission of
  the word “damage”.
- **292 skill outcomes** remain unresolved because a live
  source was unavailable, malformed, untranslated, ambiguously mapped,
  incomplete, or disagreed with the other live source.

The source-only scope intentionally leaves `ai.json` source hashes,
`analysis.json`, and generated views untouched.
